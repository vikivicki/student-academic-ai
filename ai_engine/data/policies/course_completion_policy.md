# Course Completion Policy

## Required Assessments for the Demo Dataset

Each course has one required assessment:

- C101 — Programming Test 1
- C102 — Data Science Test 1
- C103 — Web Development Test 1

This is the complete required-assessment inventory for the ACGCET demo dataset. Update this policy whenever required assessments change.

## Completion Rules

- Completed: Every required assessment has a recorded result and the student scores at least 40% in each one.
- Not Completed: At least one required assessment has a recorded result below 40%.
- Pending: One or more required assessment results are missing.

## Verification

Compare the student's enrolled course in students.csv with this required assessment inventory and the records in assessments.csv. Do not assume an arbitrary assessment is required.

## Date Handling

For evaluation using the project reference date, only assessment records dated on or before 15 January 2025 may be considered.
